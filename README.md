# Piyush Singhal — Data Analyst Portfolio

A responsive one-page portfolio website built with HTML, CSS and vanilla JavaScript.

## Included
- Hero / personal branding
- About section
- Technical skills
- Experience timeline
- Six featured projects
- Education & learning
- Contact section
- LinkedIn, GitHub and email links
- Responsive mobile navigation
- Modern dark/light visual system

## Run locally
Open `index.html` in a browser.

## Deploy
This can be deployed directly to GitHub Pages, Netlify or Vercel as a static site.
